关于本系统

面向低空航拍场景的小目标检测辅助系统：在 YOLOv8m 基线上引入 EMA 注意力、DySample 动态上采样、Slim-Neck（GSConv / VoVGSCSP）、 NWD 损失 与 P2 小目标检测分支，在 VisDrone-2019 上做 10 类检测， 并叠加北斗定位给出目标的地理坐标估算。

VisDrone-2019 DET
类别数
